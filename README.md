# How to Install the Mod

TrueGaer mod base on [CircuitLord's VR Mod](https://github.com/CircuitLord/CircuitLordVRModInstaller/releases/latest/download/CircuitLordVRModInstaller.exe)

1. Download and install [CircuitLord's VR Mod](https://github.com/CircuitLord/CircuitLordVRModInstaller/releases/latest/download/CircuitLordVRModInstaller.exe).
2. Once the installation is complete, click the **Confirm** button below to install the TrueGear Mod.
